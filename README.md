# GWAS Visual Lab
A webpage for interactive review for GWAS basic concept course built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — course structure

No build step or server is required.

## Local preview
Open `index.html` directly in a modern browser. A local web server is optional.

## Data and quiz behavior

- Topic progress and quiz state are stored in the browser with `localStorage`.
- Data are not sent to a server.
- Each browser or device keeps its own progress.
- **RESET PROGRESS** clears the course and generates a different random set of eight quiz questions.

## Updating the site

Replace the files in the repository with the revised versions and commit the changes. GitHub Pages will publish the update automatically.
